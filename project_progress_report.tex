\section{Project Overview \& Objectives}
VoteSetu is an academic cybersecurity initiative aimed at developing a resilient e-voting platform that leverages modern cryptographic protocols to ensure election integrity. The system address three primary threats: identity fraudulent registration, database tampering by privileged insiders, and the non-verifiability of cast ballots.

\subsection{Primary Technical Objectives}
\begin{itemize}[label=\textcolor{secondary}{\textbullet}]
    \item \textbf{High-Assurance Identity:} Leveraging DigiLocker-linked Aadhaar verification to anchor digital accounts to verifiable physical identities.
    \item \textbf{Reactive Security Hub:} Implementation of an out-of-band sentinel that monitors the database at the document level to detect modifications not triggered by authorized application logic.
    \item \textbf{Ballot Immutability:} Creating a receipt-based hash chain for every vote cast, ensuring that any insertion, deletion, or modification results in a cryptographically identifiable break.
\end{itemize}

\subsection{The Voting Lifecycle (Encryption & Chaining)}
When a voter selects a candidate, the system performs a multi-stage cryptographic operation:
\begin{enumerate}
    \item \textbf{AES Payload Encryption:} The ballot payload (ElectionID + CandidateID) is encrypted with AES-256 for confidentiality.
    \item \textbf{RSA Key Wrap:} The AES key is encrypted with the Administrator's RSA Public Key.
    \item \textbf{Hash Chaining:} The new vote's unique hash $H_n$ is computed as $\text{SHA256}(H_{n-1} + \text{EncryptedPayload})$. This creates a cryptographically linked ledger.
\end{enumerate}
